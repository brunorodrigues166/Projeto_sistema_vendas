#Análise do Sistema

#1. Objetivo

O sistema tem como objetivo auxiliar a organização e gestão de vendas e de estoque de uma empresa familiar que comercializa três produtos.

#2. Escopo

O sistema deve permitir o cadastro de produtos, controle de estoque, apresentação dos produtos em um site, realização de pedidos e geração de relatórios de vendas.

#3. Usuários

##Administrador
-Cadastrar produtos
-Consultar estoque
-Consultar vendas
-Gerar vendas

##Cliente
-Visualizar produtos
-Realizar pedidos

#4. Requesitos funcionais
##RF01-Cadastro de produtos 
O sistema deve permitir cadastrar os três produtos.

##RF02- Dados do produto
O cadastro deverá possuir:
-Código
-Nome
-Descrição
-Custo
-Estoque disponível
-Imagem

##RF03 - controle de estoque
O sistema deverá permitir consultar a quantidade disponível
de cada produto.

##RF04 - Catálogo
O site deverá apresentar os produtos disponíveis

##RF05 - Pedido
O cliente deverá poder realizar um pedido

##RF06 - Baixa de estoque
A realização de um pedido deverá diminuir a quantidade correspondente no estoque

##RF07 - Relatório diário
O sistema deverá permitir consultar as vendas do dia

##RF08 - relatório semanal
O sistema deverá permitir consultar as vendas da semana

##RF09- Relatório mensal
O sistema deverá permitir consultar as vendas do mês

##RF10 - Filtro de datas
O sistema deverá permitir selecionar um período para consultar.

##RF11 - Gráfico
O sistema deverá apresentar um gráfico comparativo da venda dos três produtos
