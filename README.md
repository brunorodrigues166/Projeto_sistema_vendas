# Projeto Sistema de Vendas

Sistema desenvolvido para auxiliar uma empresa familiar no gerenciamento
de produtos, estoque e vendas.

## Objetivo

O sistema tem como objetivo realizar o cadastro de produtos,
gerenciar o estoque, permitir pedidos de compra e gerar relatórios
de vendas.

## Estrutura do projeto

- `docs/` - Documentação e análise do sistema
- `frontend/` - Interface do site
- `backend/` - Sistema e regras de negócio
- `dados/` - Dados utilizados pelo sistema
- `imagens/` - Imagens dos produtos

## Funcionalidades

- Cadastro de produtos
- Controle de estoque
- Catálogo de produtos
- Pedido de compra
- Baixa automática do estoque
- Relatório diário
- Relatório semanal
- Relatório mensal
- Filtro por datas
- Gráfico comparativo das vendas
